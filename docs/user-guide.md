# 实验室同桌 · 使用说明

双击 **LabPals.exe**。适用于 Windows 10 / 11，使用 Windows 自带的 .NET Framework 4.x。便携单文件，无需安装、联网或另装浏览器运行环境。

已有用户继续使用原先的角色、大小、位置和偏好。首次启动默认为琉华、小号、键盘跟随开启。

| 操作 | 效果 |
| --- | --- |
| 轻点角色 | 各自的表情回应，约 0.9 秒恢复；睡着时叫醒 |
| 按住左键拖动 | 移动角色，松开后保存位置 |
| 右键角色或托盘试管图标 | 打开设置 |
| 点击其他窗口、桌面或按 Esc | 关闭设置 |
| 休息一会儿 | 使用角色独立睡姿；再次点击或通过设置叫醒 |
| 收起到托盘 | 显式隐藏，双击托盘图标找回 |
| 找回位置 | 返回主屏右下角 |
| 鼠标穿透 | 点击落到后面的应用，通过托盘打开设置并关闭穿透 |
| 退出 | 完全关闭桌宠并保存设置 |

重复启动会找回已运行的同桌。角色不占任务栏按钮，不抢键盘焦点；默认置顶，设置里可调整。

键盘按下时立即落掌，左右手独立；空格双手，松开平滑回弹。长按保持接触，系统自动重复不制造额外敲击。待机仅偶尔眨眼。自动休息在 3 分钟无输入后发生，输入可叫醒；手动休息只由点击或设置叫醒。

「安静陪伴」暂停敲击并保留主动点击。「一起专注」可选 25 / 45 / 60 分钟，暂时安静并显示小型倒计时，到时只显示「完成」，没有声音或弹窗。计时不跨重启保存，校准系统时间不会改变本次专注时长。

四档画布为 176×154、240×210（默认）、320×280、400×350 像素，四周留有透明空间。静止时停止连续刷新，睡稳后也没有持续动作循环。

设置位于 `%LOCALAPPDATA%\LabPals\settings.xml`。程序只使用物理按键的按下/松开信号，不解析、保存或上传输入文本，也不添加开机自启。发生启动错误时可查看同目录 `error.log`。

程序较旧但位置和角色还在：先从右键设置退出旧版，再运行新版本。移动程序文件不会改变保存的偏好。
