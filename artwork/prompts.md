# 美术制作与分层记录

使用 Codex 内置 ImageGen，未使用 CLI。目标为保留已选 C 版角色，改为人手、独立点击表情及独立睡姿。

## Okabe / hands

参考：reference/Okabe.png（角色基准图）。生成原图：source/Okabe-hands.png。

```text
Use case: precise-object-edit
Asset type: final transparent sprite for a restrained anime chibi Windows desktop companion.
Input: the supplied image is the exact approved character, drawing style and costume. Preserve character identity, hair, face, palette, delicate charcoal outlines, clean restrained cel shading, and compact proportions. Genuine transparent background. No text, symbols, hearts, zzz, effects, furniture or keyboard. Single character only.
Primary request: Change ONLY both rounded closed fists at the bottom into clearly HUMAN relaxed typing hands. Preserve the head, expression, torso, clothing and cuff shape exactly. Each hand must have a visible slim wrist, small natural palm, four separate gently arched HUMAN fingers with different lengths, and a distinct side thumb. Fingers softly extended forward and slightly inward, back of hands visible, as if hovering lightly above an invisible keyboard. Not a clenched fist or mitten, no paw, no cat hand, no isolated line marks pretending to be fingers. Hands remain compact and proportional to this human chibi. Both cuffs and shoulders must stay in the same position, fingers clear of clothing. Keep complete hands inside the existing transparent canvas, with a little space below fingers. Same image framing and head position, no overall scaling.
```

## 正式素材

运行图层位于 ../assets/characters/：每人包含主图、闭眼主图、左右手分层、点击表情及睡姿各一张；共 24 张 PNG。离线工具生成 assembled/ 供查看，该目录不提交。

离线工具 tools/art/prepare-sprites.cjs 对齐未改变的头发、帽子和衣物，主图仅采用底部手部编辑。表情只取脸部，睡姿按原角色占地范围缩小并对齐下缘。运行时再按当前显示尺寸拆分左右手，保证中性姿势与主图像素一致；活动只施加在手掌图层，身体和衣物为固定前景。不再对整个下半身进行像素拉伸。


角色资料和手腕坐标统一位于 ../assets/characters.json，构建脚本据此生成运行代码。
